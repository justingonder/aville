# The Infinite Wrench


**When:** Every Friday–Sunday · 10:30pm
**Venue:** [Neo-Futurists](https://neofuturists.org/)
**Address:** 5153 N Ashland Ave, Chicago, IL 60640
**Price:** $15-20 or pay-what-you-can
**Tags:** weekly-recurring, theater, late-night, high-energy

Thirty original plays in sixty minutes, written and performed by The Neo-Futurist Ensemble. Each week features new plays that are funny, profound, elegant, disgusting, topical, irreverent, terrifying, or musical, all inspired by the lived experiences of the performers.
